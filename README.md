# 📕 PDF Toolkit Backend

Backend API for I ❤️ PDF Toolkit — 22 working PDF tools.

## 🚀 Deploy on Render

1. Fork this repo
2. Go to [render.com](https://render.com)
3. New → Web Service → Connect this repo
4. Settings:
   - Build: `npm install`
   - Start: `npm start`
5. Add Environment Variables from `.env.example`
6. Deploy ✅

## 🛠️ Local Setup

```bash
npm install
cp .env.example .env
npm run dev
